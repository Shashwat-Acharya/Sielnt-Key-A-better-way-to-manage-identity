# API Layer

This directory contains the backend API components for Silent Key identity management.

## Overview

The API layer provides various communication protocols and endpoints for client applications to interact with the identity management system.

## Structure

- **database.py** - Database connection handling and ORM setup

## Features

- RESTful API endpoints (planned)
- GraphQL support (planned)
- Database abstraction layer

## Development

Currently in development phase. The API layer will support multiple communication protocols including:
- REST API
- GraphQL
- WebSocket connections
- gRPC
- Enterprise SOAP compatibility

## Environment Setup

Ensure PostgreSQL is running (see `infra/postgres/` for initialization scripts).
