# Benchmarks

This folder records performance measurements for protocol operations and security-sensitive components.

## What to Measure

- QR generation latency
- Challenge generation latency
- Signature verification latency
- Database round-trip time for pairing and authentication flows
- C++ biometric processing latency when the core engine becomes available

## Benchmark Template

Use a small, repeatable format:

- Date
- Environment
- Commit or branch
- Metric
- Baseline
- Result
- Notes
