# Experiments

This folder tracks research experiments and implementation prototypes.

## Experiment Log Template

- Question being tested
- Hypothesis
- Method
- Inputs and environment
- Result
- Security or usability implications
- Follow-up action

## Suggested Experiment Types

- Pairing flow usability tests
- Signature scheme comparisons
- Template protection strategy comparisons
- Threshold scheme feasibility checks
- Device trust lifecycle experiments
