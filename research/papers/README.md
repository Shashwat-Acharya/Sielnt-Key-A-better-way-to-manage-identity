# Papers, Articles, RFCs, and Technical References

This is the starter bibliography for the project.

## Identity and Authentication

- NIST SP 800-63B, Digital Identity Guidelines: Authentication and Lifecycle Management
- WebAuthn Level 2 / Level 3, W3C
- FIDO2 specifications and implementation guidance, FIDO Alliance

## Cryptography and Key Management

- RFC 8032, Edwards-Curve Digital Signature Algorithm (EdDSA)
- RFC 5869, HMAC-based Extract-and-Expand Key Derivation Function (HKDF)
- RFC 8446, The Transport Layer Security (TLS) Protocol Version 1.3

## Biometrics and Template Protection

- Dodis et al., Fuzzy Extractors: How to Generate Strong Keys from Biometrics and Other Noisy Data
- Juels and Sudan, A Fuzzy Vault Scheme for Fingerprints
- ISO/IEC 24745, Biometric information protection
- Work on cancelable biometrics and secure sketch constructions

## Post-Quantum and Future Directions

- NIST Post-Quantum Cryptography standardization publications
- Research on threshold signatures and distributed key custody
