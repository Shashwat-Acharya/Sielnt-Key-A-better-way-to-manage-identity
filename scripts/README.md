# Scripts

This directory contains automation and utility scripts for building, testing, and deploying Silent Key.

## Overview

Scripts for:
- Build automation
- Project initialization
- Deployment helpers
- Testing utilities

## Usage

Scripts are typically run from the project root directory:

```bash
python scripts/script_name.py
```

## Available Scripts

Scripts in this directory will include:
- Build helpers for C++ components
- Database initialization scripts
- Deployment utilities
- Local development setup

## Development

When adding new scripts:
1. Add descriptive docstrings
2. Support command-line arguments where applicable
3. Log progress and errors clearly
4. Update this README with usage information
